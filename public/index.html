Tips & Best Practices

✅ For Best Results

Company Info: The more detailed your company description, the better the color detection. Include brand colors, values, and visual identity.

✅ For Best Results

Website URLs: Works best with company websites that have clear content. Make sure JavaScript isn't required for content display.

✅ For Best Results

Document Customization: Choose sections that matter most. Fewer sections = shorter, punchier proposals.

⚠️ Avoid This

Empty Fields: Don't leave required fields blank. The form validates to ensure all critical info is provided.

⚠️ Avoid This

Massive Uploads: Keep company text under 10,000 words for faster processing.

⚠️ Avoid This

Using Claude without API key: If you select Claude, make sure you have a valid API key. Gemini works without setup.

Frequently Asked Questions

What's the difference between Gemini and Claude AI?
+
Google Gemini: Free to use with generous rate limits. Great for quick proposals and learning. Claude 3.5: Requires API key (paid subscription), but often produces more detailed and nuanced content. Choose based on your needs and budget.
How accurate is the brand color detection?
+
The color detection works best when you provide explicit information about the company's brand colors in the description (e.g., "Our primary color is #FF6B35"). For websites, it scans the HTML. If colors aren't found, it provides sensible defaults that you can manually adjust.
Can I edit the generated documents?
+
Yes! Download the Word document (.docx) and edit it in Microsoft Word, Google Docs, or any compatible editor. The design prompts are plain text and can be modified before copying to Figma or Claude Design.
How long does generation take?
+
Typically 30-60 seconds depending on document length and API response times. You'll see a progress indicator while generation is happening. Color detection is instant (happens as you type).
What file formats are supported for upload?
+
Meeting notes can be uploaded as PDF, TXT, or DOCX files. They're used as reference material to add context to your proposal. Pitch deck links can be Google Drive URLs or pasted PDF text.
Is my data private and secure?
+
The app sends your information to Google Gemini or Anthropic's Claude API for document generation. Please review their privacy policies. Avoid sharing sensitive information in descriptions. Generated documents are created locally in your browser.
Can I use this for non-event partnerships?
+
Absolutely! While designed with event partnerships in mind, you can adapt it for vendor partnerships, sponsorships, joint ventures, or any business partnership. Just customize the sections and tone to fit your needs.
